### 3.2 The two remaining problems

Both are reload-pass register choices. Global allocation, stack slots, frame size and the loop shape all match already. `spill_regs` = [r0, r1, r2, r3, r4]. The tracer shows that every rotation event in C11 except these already matches the target.

**Problem A: prologue work1 reload (insn 1450 in the C11 trace).**
- This is the setup of the spilled `&sprite->work1` giv: an in/out reload of `ip`.
- The rotation cursor is at 3 after r0, r1, r2, r3, so it picks **r4**. The target has **r0**.
- To get r0, r4 must be unavailable at that insn, or there must be no rotation event there at all.
- If 1450 picks r0, the next event (insn 1469, the sp+16 store) still gives r0 and nothing later changes. So this one insn is the whole prologue residual.
- A related prologue diff is the `mode` store (insn 56). That is **not** a rotation event: reload.c's single-output rule (about line 1600) lets the output reload reuse the dying pinned `modePtr` r4. The target has address r4 and output r0.

**Problem B: post-loop zero register (insns 911 mode1-low X and 1121 mode0-low Y).**
- The target has `movs r2, #0; ldrsh r0, [rA, r2]`.
- thumb.md's `*extendhisi2_insn` prints `ldrsh r0,[rA,rB]` directly when the address is `(plus reg reg)`. The allocated scratch then never appears, so the target can have the same r3/r4 rotation events as ours, provided the r2 zero is a **real register** in the RTL.
- Our pinned `zero asm("r2")` is folded by combine. flow.c builds `LOG_LINKS` for hard-register sets to their uses inside one basic block, so a single-use constant set gets folded.
- **Question for GPT-6:** what plain-C shape gives a zero in r2 that combine can't fold? Candidates are a set used by two insns, or a set in a dominating block whose code position doesn't change, with no extra instructions emitted.

### 3.4 The reload tracer

`tools/trace_reload.py` (committed `1265026`, force-added because `tools/` is gitignored). The usage note is at the top of the file.

- It runs `tools/agbcc/agbcc` under ptrace and logs every `allocate_reload_reg` call made while compiling one function: insn UID, reload index, chosen register, and `last_spill_reg` (the cursor) before and after.
- It is read-only on disk. Breakpoints are patched only in the traced child's memory.
- It needs Linux/WSL x86-64. Its breakpoint and variable offsets are for the current `tools/agbcc/agbcc` binary.

From the repo root in WSL:

```sh
cc -E -DVERSION_US -Iinclude -Isrc/sprite_ai -nostdinc src/sprite_ai/swinging_platform.c > /tmp/sp.i
python3 tools/trace_reload.py /tmp/sp.i func_804A508 /tmp
```

- **Output:** it prints one line per event, for example `insn 1450  reload 0 -> r4  cursor 3 -> 4  spill_regs [0, 1, 2, 3, 4]`, and writes `/tmp/trace-sp.json`, `.s` and `.stderr`.
- **Baseline:** C11 gives 50 events.
- **UIDs move:** insn UIDs change whenever the source changes, so match events by position and register, not by UID.
- **Trial candidates:** to trace one, put the candidate into a copy of the file and preprocess that copy instead.

## 4. Reusable techniques (all confirmed by a match)

1. **Cractus: duplicate code per branch** (UpdateCractusArmSegmentPose24, session 2).
   - The original duplicated the whole x-step in both if/else branches.
   - After reload, the compiler cross-jumps the identical tails, so the output shows it once. The IF copy's reloads still move the rotation, so the ELSE copy gets `r7`.
   - Progression: pinned shared r7 scored 557, unpinned shared variable 11, duplicated per branch 0.
2. **BlackDragon: separate variables per branch** (UpdateBlackDragonAttack, session 4).
   - If the target gives the "same" variable different registers in different branches, the original had separate block-local (or macro/inline) variables.
   - One C variable is one pseudo with one hard register.
   - The fix was block-local `index`/`counter` in each case, with no goto and no shared sprite variable.
3. **Catbat: unpin to create a reload event** (UpdateCatbatPatrol, session 7, GPT-6's Experiment A in `reports/catbat_gpt6_plan.md`).
   - A pinned high-register pointer forces an expand-time copy, which is not a reload event.
   - Unpinned, `wario` has lower priority and still lands in `r8`, and the x load becomes an output reload into `r1` that advances the rotation.
   - Pins can *remove* rotation events you need.
4. **FlatWario: duplicate the final check** (FlatWarioFloating, Codex, `0e4db9a`).
   - The final animation-time check is duplicated in both arms of `if (counter)`, each arm ending in `goto returnFF` / `goto decrementFrame`.
   - Same family as Cractus: identical-looking code per branch changes allocation and layout, then gets merged back.
5. **Derby: trace the reload cursor, then supply the missing event with useful work** (DrawHomerunDerby, Codex, `89a6f56`).
   - Trace `allocate_reload_reg` to find which event is missing or extra.
   - Then change a source shape so a *necessary* operation creates that event. For Derby that was `oamByteMask = -15;` directly, which thumb.md splits into `mov r0,#15; neg r0,r0` through an allocator-chosen low temp.
   - Never add a dummy operation.
6. **do-while(0): raise allocation priority without changing code** (func_804A508, session 15).
   - global.c `find_reg` pass 0 only takes registers already in `regs_used_so_far`, so register order follows allocno priority `log2(refs)*refs/live_length`.
   - flow.c adds `loop_depth` to `REG_N_REFS` per reference. Wrapping a value's uses in `do { } while (0)` (nest it for more) raises that value's priority without emitting any code.
   - Try this before pinning.
7. **Sibling-copy: write it like a matched sibling** (DrawSoundRoomSprites, session 17, 42.9% to a match in 7 compiles).
   - For large or incomplete functions, find an already-matched function with the same idiom and copy its loop shape literally. For OAM drawing that is `RenderStageEntrySprites` (stage_entry.c) and `RenderVortexCutsceneOam` (vortex_cutscene.c):
     ```c
     for (; currentSlot < nextSlot; currentSlot++) {
         attr = *(src++); *(dest++) = attr; gOamBuffer[currentSlot].split.y = ...;
         attr = *(src++); *(dest++) = attr; gOamBuffer[currentSlot].split.x = (attr + X) & 0x1FF;
         *(dest++) = *(src++); gOamBuffer[currentSlot].split.priority = 0; dest++;
     }
     ```
   - loop.c then produces the reversed counters and hoisted masks by itself.
   - decomp.wtf truncates long targets at about 580 lines. Get the full target with `arm-none-eabi-objdump -d -r --no-show-raw-insn expected/us/obj/<unit>.o`.

Also useful: the reload-rotation summary in `MATCHING_PROGRESS.md` ("Reload register rotation") and CheckWarioHorizontalCollision's trick there: a load into a variable pinned to a high register (`asm("r12")`) emulates a reload of a spilled pseudo with no extra code.

## 5. Rules

- **Claim before testing.** Claim the function on decomp.wtf (`claim_function`) before any compile for it, local trials included. Never work on a function another agent holds. Release with notes when you stop.
- **Never pin r7.** It is `FRAME_POINTER_REGNUM` in Thumb RTL and isn't reserved, so pins can miscompile. Sessions 5 and 14 both hit this. Before any register-pin experiment, scan the session log for known warnings.
- **Don't touch `tools/agbcc`.** Leave the submodule and its compiler settings alone. It shows as modified (`gcc_arm/obstack.c`, `gcc_arm/splay-tree.c`); that is deliberate. Never stage it.
- **Commit by name only.**
  - Use `git add <path>` for named files. Use `git add -f` for files under the gitignored `tools/`.
  - Never use `git add -A`, `git reset --hard`, `git clean` or a force-push. Push to `myfork` without force and confirm with `git ls-remote --heads myfork decomp-wtf`.
  - Commit a match only after objcmp verification.
- **Verify with objcmp.py.** After any match, build all objdiff units and run the check (from WSL, repo root):
  ```sh
  make -k $(python3 -c "import json;print(' '.join(u['base_path'] for u in json.load(open('objdiff.json'))['units']))")
  python3 tools/objcmp.py
  ```
  The expected result is one fewer than 14 differing, with every matched function identical.
- **No inline asm.** `asm("")` barriers are also out. Register asm variables (`register T x asm("rN")`) are allowed.
- **`compile_and_diff` is not read-only.** It writes the function into `src/` and auto-commits on a match. Use a local harness for trials.
- **Budget:** about 20 compiles per session (local trials count). When you reach it, write up your findings.
- **Log every session in `MATCHING_PROGRESS.md`.** Record what was tried, the line counts or scores, and where the result lives (git, working tree, or decomp.wtf saved best).
- **Never publish game code or assets.** No ROMs, extracted Nintendo assets, auth tokens or local secrets in commits. Check for absolute user paths before committing reports.
