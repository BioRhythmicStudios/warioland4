# WL4 Pixel

`wl4-pixel.ttf` is a private Windows font generated from the actual SDL 3.4.18
`SDL_RenderDebugText` glyphs used by the launcher's Settings window. It covers
ASCII and Latin-1 printable characters, preserving the 8x8 shapes and spacing.
The main launcher uses 16-pixel cells (2x); the heading uses 32-pixel cells (4x).
No antialiasing is requested. Windows title bars and native file-selection dialogs
retain the operating system font. No font is installed system-wide.

SDL's [debug font source](https://github.com/libsdl-org/SDL/blob/release-3.4.18/src/render/SDL_render_debug_font.h)
attributes the glyphs to Marcel Sondaar / IBM public-domain VGA fonts. This is an
altered font packaging, generated by our converter from SDL's rendered bitmap,
not an original SDL TrueType asset. The SDL distribution notice is retained in
`SDL-LICENSE.txt`.

Normal launcher builds consume the committed TTF directly. Regeneration only:

1. Compile `port/tools/launcher_font_atlas.c` against the SDL3 used by the build.
   Put the matching SDL3.dll beside the utility and run it with a new `.bmp` output
   path under `build/`. It uses a software renderer and opens no window.
2. Install the build-only Python package fontTools into a disposable location,
   then run `python port/tools/make_launcher_font.py ATLAS.bmp OUTPUT.ttf`.
3. Review the generated font before replacing this asset. The generation script
   records a fixed timestamp for repeatable output. No Python package is needed
   by the launcher or its normal CMake build.

The 2026-10-19 GDI check rasterized all 191 glyphs and compared all 48,896 display
pixels against the SDL bitmap at 2x: zero mismatches. Runtime registration uses
AddFontMemResourceEx and removes the private font when the launcher exits.
